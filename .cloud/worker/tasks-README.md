# 山水工程 AI Worker · 任务队列

把任务文件（`.md`）丢进这个目录，worker 会自动领取执行，结果存到 `../done/<同名>.result.md`。

## 任务格式

```markdown
（直接写任务正文，AI 会收到全文）

建议包含三要素：
1. 目标：要它干什么
2. 上下文：相关文件路径 / 背景（AI 会自己去 ~/work/ 读）
3. 期望产出：格式 / 详细程度
```

## 示例

```
tasks/2026-10-13-v6-risk.md
---
分析 ~/work/shanshui 中 v6 三区缝合方案（UTF + Tectonic + 原版）的技术风险，
重点评估 UTF 自定义 density function 类型的运行时注册问题。
产出：风险清单（按严重度排序），每条附缓解措施。500 字以内。
```

## 规则

- 文件名即任务 ID，用日期开头便于排序（worker 按文件名顺序领取）
- 一个文件一个任务，执行完移入 `done/` 归档，结果在同名 `.result.md`
- 进行中的任务被重启中断 → 文件没移走 → 自动重做，天然断点续作
- API Key 未配置时 worker 空转不报错，填好 `~/.env` 自动生效
