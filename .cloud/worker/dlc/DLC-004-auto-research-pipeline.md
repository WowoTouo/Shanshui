# DLC-004 · 全自动研究工作流
> DLC = 技能扩展卡。本卡定义全自动研究环境的运行规则。
> 挂载方式：worker.py 启动时读取 `/home/agent/dlc/*.md`（按文件名排序）拼进 system prompt。
> 版本：v1.0 · 2026-10-14
---
## 1. 依赖管理（自动识别、自动安装）
- 研究所需依赖包和库无需手动授权，自动识别缺失依赖并自动安装；
- Python 依赖使用 uv pip install，系统包使用 apt-get install -y（非交互模式）；
- 安装前先检查是否已存在，避免重复安装浪费资源；
- 安装失败时记录到日志并尝试替代方案，不阻塞主流程。

## 2. 研究执行（自动检测、自动修复）
- 根据任务目标自动开展研究；
- 遇到 bug 或错误时自动检测根因并自行修复，无需人工干预；
- 修复失败时记录阻塞点到日志，尝试替代路径继续推进；
- 每次修复后重新验证，直到通过或达到最大重试次数。

## 3. 产物保存与同步（自动上传云端、自动分类）
- 所有研究产物（代码、模型、数据、报告等）必须自动上传到云端存储；
- 按项目、类型、日期等维度自动分门别类整理；
- 利用现有 sync-research.sh（每 2 小时自动同步到线上仓库）确保本地清理后不会丢失；
- 产物目录结构：research/results/（任务结果）、research/playbooks/（操作手册）、research/learnings/（知识沉淀）、research/reports/（研究报告）、research/code/（代码产物）。

## 4. 运行指南（自动生成 README）
- 每次研究任务完成后，自动生成一份清晰的运行指南或 README；
- 内容包含：环境配置、执行步骤、注意事项、复现方法；
- 存放位置：与产物同目录的 README.md 或 RUNBOOK.md。

## 5. 任务启动前检查（云端对比、差异确认）
- 每次开始新任务前，先完整浏览云端存储中的所有相关文件；
- 与当前服务器本地文件进行对比，确认差异后再基于最新状态开始工作；
- 对比方式：git fetch + git diff 查看远程与本地差异；
- 如有冲突或未同步的本地改动，先处理冲突再开始新任务。

## 6. 开销控制
- 依赖安装与云端同步为零 token 操作（纯 shell 脚本）；
- 启动前对比使用 git 命令，不经过模型；
- 运行指南生成在任务完成后作为产出的一部分，不额外消耗 token。
